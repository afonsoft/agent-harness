## 1. User Story
**As a** Coding AI Agent User,
**I want** a workspace-centric layout inspired by OpenWebUI and modern IDEs,
**So that** I can focus on agent execution, code changes, and terminal output without dashboard clutter.

## 2. Scope
### In Scope
- **Layout Core:** Refactoring `MainLayout.razor` to support split-view container patterns.
- **Sidebar Evolution:** Transitioning from generic management modules to session/worktree-centric tree navigation.
- **Panelization:** Promoting `ConversationWorkspacePanel` and `RunTerminal` to first-class layout components.
- **Visual Cleanliness:** Replacing saturated pastel status backgrounds with subtle neutral borders and indicators.

### Out of Scope
- Backend logic changes or API modifications.

## 3. Technical Context
- **Files Investigated:** `src/Taskboard.Blazor/Layout/MainLayout.razor`, `src/Taskboard.Blazor/Layout/NavMenu.razor`, `src/Taskboard.Client/wwwroot/css/site.css`.
- **Target Components:** `ConversationWorkspacePanel`, `AiChat`, `KanbanBoard`.

## 4. Requirements
- **RF-001 (Context Sidebar):** Prioritize session history and active worktrees over static module links.
- **RF-002 (Split-Pane Workspace):** Support side-by-side Chat and Workspace (Editor/Terminal/Diff) views.
- **RF-003 (Design Density):** Reduce visual noise, shadow weight, and border radii to match an IDE-grade developer workbench.

## 5. Acceptance Criteria
- Transitioning from dashboard view to an agent session instantly renders the split-pane workspace.
- Responsive design collapses secondary panels into bottom sheets or offcanvas drawers on mobile viewports.
