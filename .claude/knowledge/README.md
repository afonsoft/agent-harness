# `.claude/knowledge/`

Curated knowledge notes for this repository — the "Knowledge" column of the platform table in `CLAUDE.md`.

## Convention

- One Markdown file per topic (`<slug>.md`, kebab-case).
- Content here is **curated and human/agent-reviewed** — unlike `.claude/memory/` (session state, orchestrator stats, raw session artifacts), this directory holds distilled, durable knowledge: runbooks, invariants, integration notes, post-incident learnings.
- Keep each note self-contained; link to code/specs rather than duplicating them.
- Long-lived docs belong in `docs/`; this directory is for agent-facing working knowledge.
